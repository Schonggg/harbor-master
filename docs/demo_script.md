# Demo script (逐帧)

> 第一天就写，最后一小时只改数字和停顿。

## 0:00–0:20 钩子
「别的 AI 抢着告诉你它找到了什么。Harbormaster 知道自己什么时候不该开口。」
打开 Bridge → Board 三色卡片。

## 0:20–0:50 庭审
点 **Run inbox** → 切到 **Court**。
旁白：指控出现 → 后缀剥离 / LOCODE / 单位换算 / 数量抽取依次辩护 → 真差异才 HOLD。

## 0:50–1:20 引航台
切到 **Pilot**。把一条 UNCERTAIN 点成 Accept as MATCH。
旁白：人工裁决写入账本，历史案例自动回扫，队列变短。

## 1:20–1:45 自主性旋钮
切到 **Dial**。拧高阈值 → PILOT 变多。
「自主性是旋钮，不是开关。」

## 1:45–2:15 砸场
切到 **Chaos**。依次砸 LLM / OCR / 附件 / 空邮件。
每一次都必须落到 PILOT + failure code，不能瞎判 CLEAR。

## 收束
打开 ADR-001：「LLM never judges。」
Make test 绿屏一闪（排练时备好）。
