# Field risk rationale

| Field | Why expensive |
|---|---|
| consignee | Misdelivery / title risk |
| notify_party | Often SAME AS CONSIGNEE — false alarms common |
| port_of_loading | Route / insurance basis |
| port_of_discharge | Wrong POD = wrong continent |
| container_count | Capacity / charges |
| gross_weight | Safety + customs |
| vessel_voyage | Cut-off / connection |

Exposure USD figures in `config/risk_matrix.yaml` are demo-calibrated, not actuarial.
